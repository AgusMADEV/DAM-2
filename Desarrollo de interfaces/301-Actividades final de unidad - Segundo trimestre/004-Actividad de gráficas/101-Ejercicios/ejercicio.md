## 🚀 Cómo Empezar

1. Navega a la carpeta del proyecto:
   ```
   002-Proyecto de reconocimiento de voz y camara/101-Ejercicios/
   ```

2. Abre `index.html` en tu navegador para ver el menú principal

3. Elige qué demo quieres probar:
   - **Nuevo en interfaces naturales**: Empieza con las demos simplificadas
   - **Con experiencia**: Ve directamente a la aplicación completa

## ✨ Características del Proyecto

### Reconocimiento de Voz 🎤
- Comandos en español
- 5 operaciones diferentes (agregar, eliminar, completar, leer, limpiar)
- Conversión de números en texto
- Síntesis de voz para feedback

### Reconocimiento de Gestos 👋
- 4 gestos diferentes detectados
- MediaPipe Hands con 21 landmarks
- Sistema de cooldown
- Feedback visual en tiempo real

### Tecnologías Utilizadas
- Web Speech API
- MediaPipe Hands
- Canvas API
- HTML5 + CSS3 + JavaScript ES6+
