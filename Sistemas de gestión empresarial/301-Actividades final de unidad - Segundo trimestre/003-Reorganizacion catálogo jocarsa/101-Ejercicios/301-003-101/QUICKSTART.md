# Guía Rápida de Inicio

## Instalación

1. Asegúrate de tener Python instalado (versión 3.8 o superior)

2. Instala las dependencias:
```bash
pip install -r requirements.txt
```

## Ejecución

Desde la carpeta del proyecto, ejecuta:

```bash
python app.py
```

La aplicación se abrirá automáticamente en tu navegador en http://127.0.0.1:5000/

## Primeros Pasos

1. **Dashboard**: Verás un dashboard vacío inicialmente
2. **Crear Datos**: Usa los módulos de la barra lateral para crear:
   - Clientes en el módulo CRM
   - Proyectos en Gestión de Proyectos
   - Formularios en Formularios Online
3. **Ver Datos**: El dashboard se actualizará automáticamente
4. **Generar Informes**: Usa el módulo de Informes para ver análisis cruzado

## Características Destacadas

- **Integración**: Los datos fluyen entre módulos
- **Dashboard**: Vista consolidada de todo el sistema
- **Informes**: Análisis que combinan datos de múltiples fuentes

¡Disfruta explorando la suite!
