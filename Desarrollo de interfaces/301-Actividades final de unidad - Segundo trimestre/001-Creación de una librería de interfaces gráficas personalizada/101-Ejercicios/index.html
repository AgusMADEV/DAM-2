Librería Personal de Componentes de Interfaz de Usuario

Bienvenido al Ejercicio Personal

Este proyecto presenta una librería de componentes UI desarrollada desde cero, implementada en versiones progresivas desde lo más básico hasta características avanzadas.

VERSIÓN 1.0

Versión Básica - Fundamentos

La primera versión implementa los componentes fundamentales con funcionalidad básica. Perfecta para entender la estructura y arquitectura de la librería.

  • Tarjetas de Estadísticas (StatsCard)
  • Tabla Simple con estilos (SimpleTable)
  • Sistema de diseño con variables CSS
  • Patrón UMD para compatibilidad
  • Diseño responsive básico
Ver Demo v1.0 Documentación
VERSIÓN 2.0

Versión Mejorada - Interactividad

La segunda versión añade interactividad completa con búsqueda, ordenamiento, paginación y un nuevo componente de gráficos. Esta versión cumple todos los requisitos del ejercicio de clase.

  • StatsCard con animaciones e indicadores
  • DataTable con búsqueda en tiempo real
  • Ordenamiento por columnas (asc/desc)
  • Paginación completa con navegación
  • Gráficos de barras con Canvas
  • Métodos públicos para actualización
Ver Demo v2.0 Documentación
