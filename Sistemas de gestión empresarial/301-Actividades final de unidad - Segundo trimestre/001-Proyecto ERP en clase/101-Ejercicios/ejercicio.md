# ⚽ TotalKit ERP - Ejercicio Final de Evaluación

## 🎯 Actividad Realizada

Este ejercicio consiste en el desarrollo de un **Sistema ERP para una tienda online de camisetas de fútbol**, inspirado en el proyecto de clase pero con temática y funcionalidades propias.

## 📁 Archivos Creados

1. **base_datos.sql** - Base de datos completa con:
   - 17 tablas relacionales
   - Datos reales de equipos famosos
   - 3 vistas optimizadas
   - Campos especializados para camisetas de fútbol

2. **index.php** - Sistema ERP con:
   - Sistema de login/sesiones
   - Dashboard con estadísticas
   - Gestión CRUD de todas las tablas
   - Gráficos de camisetas por equipo
   - Generación dinámica de formularios

3. **estilos.css** - Diseño moderno con:
   - Más de 800 líneas de CSS personalizado
   - Tema verde césped (colores futbolísticos)
   - Diseño responsive
   - Animaciones y transiciones
   - Componentes modernos

4. **README.md** - Documentación completa del proyecto
5. **INSTALACION.md** - Guía paso a paso de instalación

## 👕 Tipos de Productos

- **Primera Equipación**: Camisetas titulares
- **Segunda Equipación**: Camisetas suplentes
- **Tercera Equipación**: Camisetas alternativas
- **Versión Aficionado**: Sin personalización
- **Versión Jugador**: Con nombre y número (Bellingham #5, Lewandowski #9, Messi #10, etc.)

## 🎨 Características Únicas

1. **Gestión por Temporadas**: 2022/23, 2023/24, 2024/25, 2025/26
2. **Control de Tallas**: XS, S, M, L, XL, XXL
3. **Personalización**: Jugadores con nombre y dorsal
4. **Ligas Reales**: LaLiga, Premier League, Serie A, Bundesliga, Ligue 1
5. **Marcas Auténticas**: Nike, Adidas, Puma, etc.
6. **Cliente con Equipo Favorito**: Los clientes tienen su equipo preferido

## 🚀 Cómo Usar

1. Importar `base_datos.sql` en MySQL (crear BD: `tienda_camisetas`)
2. Configurar credenciales en `index.php`
3. Abrir en navegador: `http://localhost/...`
4. Login: **admin** / **admin123**
