# Sistema de Tareas - Versión Básica

Versión simplificada del sistema de gestión de tareas con interfaces naturales.

## Características

- ✅ Reconocimiento de voz en español
- ✅ Detección de gestos con la mano
- ✅ Gestión básica de tareas

## Comandos de Voz

- **"agregar [nombre]"** - Añade una nueva tarea
- **"eliminar [número]"** - Elimina tarea por índice
- **"limpiar"** - Elimina todas las tareas

## Gestos

- **✌️ Dos dedos** - Añadir nueva tarea
- **✊ Puño cerrado** - Eliminar última tarea

## Uso

1. Abre `index.html` en tu navegador
2. Permite acceso al micrófono y cámara
3. Usa comandos de voz o gestos para gestionar tus tareas

## Tecnologías

- Web Speech API (reconocimiento y síntesis de voz)
- MediaPipe Hands (detección de gestos)
- HTML5 + CSS3 + JavaScript vanilla

## Requisitos

- Navegador moderno (Chrome, Edge, Safari)
- Micrófono y cámara web
- Conexión a internet (para librerías CDN)
