🚀 Cómo Iniciar la Aplicación

Paso 1: Iniciar XAMPP Apache

Abre el Panel de Control de XAMPP y asegúrate de que Apache esté ejecutándose.

Paso 2: Ejecutar el Monitor de Servidor

Opción A - Ejecución única (ya ejecutado):

python server_monitor.py

Opción B - Ejecución continua (recomendado):

.\run_monitor.ps1

El script se ejecutará cada 60 segundos recopilando nuevos datos.

Paso 3: Acceder al Dashboard

Haz clic en el botón "Abrir Dashboard" abajo o accede manualmente a la URL.

🎯 Abrir Dashboard 📖 Ver Documentación Completa

⚙️ Personalización

💡 Consejo: Abre el archivo index.php para personalizar:
  • Tipos de gráficos (line, bar, pie)
  • Discos e interfaces de red a monitorear
  • Credenciales de autenticación
  • Cantidad y disposición de gráficas

Ejemplo de Configuración de Endpoint

// Cambiar el tipo de gráfico de CPU a barras ['endpoint' => 'cpu', 'type' => 'bar', 'label' => 'CPU'], // Monitorear un disco específico de Windows ['endpoint' => 'disk_io', 'type' => 'line', 'label' => 'DISK I/O', 'disk' => 'PhysicalDrive0'], // Cambiar la interfaz de red ['endpoint' => 'bandwidth', 'type' => 'line', 'label' => 'BANDWIDTH', 'iface' => 'Ethernet'],

📊 Características del Dashboard

  • ✨ Actualización automática cada 10 segundos

🎓 Ejercicios Sugeridos

1. Experimentar con Tipos de Gráficos

Cambia los tipos de visualización entre 'line', 'bar' y 'pie' para ver cuál representa mejor cada métrica.

2. Añadir Nuevas Métricas

Agrega más endpoints al array $endpoints para monitorear otros recursos del sistema.

3. Personalizar el Diseño

Modifica los estilos CSS en index.php para cambiar colores, tamaños y efectos visuales.
