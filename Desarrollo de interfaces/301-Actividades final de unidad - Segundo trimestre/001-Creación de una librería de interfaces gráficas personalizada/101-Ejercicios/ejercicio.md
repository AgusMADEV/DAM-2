# Ejercicio Personal - Librería de Interfaces Gráficas Personalizada

## 📝 Enunciado del Ejercicio

Los lenguajes HTML y CSS nos proporcionan una serie de elementos de interfaz gráfica predeterminados que son de extrema utilidad en la gran mayoría de los casos. Existen otros casos en los cuales necesitamos personalizar nuestras propias interfaces de usuario.

### Objetivo

El objetivo de esta práctica consiste por una parte en que demuestres que tienes un amplio control sobre los elementos de interfaz de usuario existentes, y a continuación, se trata de que demuestres que puedes ampliar y personalizar los elementos predeterminados de interfaz de usuario, tanto desde un punto de vista visual, como, sobre todo, desde un punto de vista funcional.

### Requisitos

- Desarrollar un ejercicio personal a partir del ejemplo visto en clase
- Puedes partir desde el código de la última versión del ejercicio tal y como lo hemos trabajado en clase, o bien puedes escribir el código desde cero
- La temática de base del ejercicio debe respetar el ejercicio de clase
- Crear una primera versión simple/básica, y luego ir mejorándola poco a poco

## 📦 Solución Desarrollada

He creado una librería de componentes UI llamada **AgusmaLab** en dos versiones progresivas:

### ✅ Versión 1.0 - Básica
Carpeta: `v1-basico/`

Componentes implementados:
- **StatsCard**: Tarjetas de estadísticas visuales
- **SimpleTable**: Tabla HTML mejorada con estilos

### ✅ Versión 2.0 - Mejorada
Carpeta: `v2-mejorado/`

Componentes implementados:
- **StatsCard Mejorada**: Con animaciones e indicadores de cambio
- **DataTable**: Tabla con búsqueda, ordenamiento y paginación
- **BarChart**: Gráfico de barras con Canvas

## 🚀 Cómo Probar

1. Abre `v1-basico/index.html` en tu navegador para ver la versión básica
2. Abre `v2-mejorado/index.html` para ver la versión mejorada con todas las funcionalidades
