✓ El servidor acepta múltiples clientes
✓ Los mensajes se distribuyen a todos los clientes (excepto al remitente)
✓ Los emojis y caracteres UTF-8 funcionan correctamente
✓ El comando /salir desconecta limpiamente
✓ El servidor registra todas las actividades
✓ Las notificaciones de unión/salida funcionan


## PROBLEMAS COMUNES

### Error: "Address already in use"
- Solución: El puerto 5000 está ocupado. Espera 30 segundos o cambia el PORT en ambos archivos.

### Error: "Connection refused"
- Solución: El servidor no está ejecutándose. Inicia primero el servidor.

### No se ven los mensajes
- Solución: Verifica que HOST y PORT son iguales en servidor y cliente.

### Caracteres raros en lugar de emojis
- Solución: Tu terminal no soporta emojis. Usa Windows Terminal, PowerShell 7, o WSL.
